# Opnory Support

This document explains how to get help with Opnory and where to direct different types of inquiries.

---

## General Support

For questions about using Opnory, configuration, integrations, or general assistance:

**support@opnory.com**

---

## Security Vulnerabilities

**Do not open public GitHub issues for security vulnerabilities.**

Report security issues through the dedicated channel:

**security@opnory.com**

See the full [Security Policy](SECURITY.md) for scope, submission guidelines, and coordination expectations.

---

## Privacy Requests

For data-subject access requests, deletion requests, or other privacy inquiries:

**privacy@opnory.com**

See the [Privacy Policy](PRIVACY.md) for details on data processing practices and your rights.

---

## Open Source Bug Reports and Feature Requests

Once the Opnory source-code repository (`opnory/opnory`) is public, use its GitHub Issues for:

- Bug reports in the open-source code
- Feature requests
- Documentation improvements
- Pull requests

Do not use the open-source issue tracker for security vulnerabilities or privacy requests.

---

## Opnory Cloud Service Issues

Customers with an active Opnory Cloud subscription should use the support channel specified in their subscription plan or Order Form. This may include a dedicated support portal, priority email, or in-product support widget.
